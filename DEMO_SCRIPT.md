# SaranyaMart — Rehearsed Evaluation Demo Script
**Duration**: 2 – 3 Minutes  
**Target Audience**: Faculty Evaluation Panel / Reviewers  
**Application URL**: `http://localhost:8080`

---

## 🎬 Step-by-Step Evaluation Walkthrough

### Phase 1: Guest Browsing & Category Filtering (0:00 - 0:30)
1. Open browser to `http://localhost:8080`.
2. Point out the hero banner, category bar (`All Products`, `Laptops`, `Mobiles`, `Electronics`, `Fashion`), currency selector (`₹ INR`, `$ USD`, `€ EUR`), and dark/light mode toggle.
3. Click the **"Laptop"** category tab to demonstrate real-time catalog filtering.

### Phase 2: User Authentication & Buyer Shopping Journey (0:30 - 1:15)
1. Click **"Quick Demo Accounts" -> "Buyer"** (`buyer@saranyamart.com`).
2. Point out the avatar update in the top right corner.
3. Click **"Add to Cart"** on *High Performance Laptop*.
4. Open the **Shopping Cart Modal** icon in header.
5. Apply promo coupon code `SARANYA10` and point out the 10% discount deduction (-₹4,500).
6. Click **"Proceed to Checkout"**, enter shipping address *"123 Anna Salai, Chennai"*, and click **"Confirm Order Now"**.
7. Open **"My Order History"** and click **"Print / Save as PDF Invoice"** to display the GST invoice.

### Phase 3: Seller Control Center (1:15 - 1:45)
1. Click user avatar -> Logout, then click **"Quick Demo Accounts" -> "Seller"** (`seller@saranyamart.com`).
2. Point out the **Seller Control Center** stat cards (*My Listings*, *Inventory Value*, *Orders Received*).
3. Click **"Add Product"** and add a test item to demonstrate seller listing management.
4. Show the incoming customer orders table.

### Phase 4: Admin Control Panel (1:45 - 2:15)
1. Logout and log in as **"Admin"** (`admin@saranyamart.com`).
2. Demonstrate the **Registered Users**, **All Orders**, and **Product Moderation** tabs.
3. Click **"Export Users CSV"** and **"Export Orders CSV"** to demonstrate platform report generation.

### Phase 5: AI Chatbot Assistant Integration (2:15 - 3:00)
1. Click the floating **AI Robot button** in the bottom right corner to slide open the chat panel.
2. Point out the active provider status pill (`Mock Mode`).
3. Click the suggestion chip **"🔄 Return Policy"**; point out the instant response: *"7 days return policy..."*.
4. Click the action chip **"💻 Browse Laptops"**; observe the main marketplace catalog filter to Laptops automatically!
5. Type custom question: *"How do I use a coupon code?"* and demonstrate rate-limiting and response formatting.
